# Homework 02: Tooling Setup

This homework sets up a reproducible Python project environment.

It includes:

- a clear project folder structure;
- a `.env` file for local configuration and a `.env.example` template;
- `src/config.py` for loading environment variables and defining paths;
- a Jupyter Notebook that checks the Python environment and uses NumPy;
- `requirements.txt` to record project dependencies.
